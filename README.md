# BIBLIOTECA

Sistema de gerenciamneto de uma biblioteca desenvolvido usando PHP puro, MySQL, CSS e JavaScript.

O projeto permite cadastrar e gerenciar categorias, livros, consultar detalhes, além de cadastro, login e gerenciamento do perfil de usuarios.

## Requisitos
Para executar o projeto localmente, é necessário ter:

* **XAMPP**;
* **PHP 8 ou superiror**;
* **MySQL 5.7 ou superior**;
* **Apache**;
* **Navgeador Web Atualizado**;
